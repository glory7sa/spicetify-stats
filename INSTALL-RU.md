# Stats — новый дизайн

## Установка на Windows

1. Закрой Spotify полностью.
2. В PowerShell выполни `spicetify -c`. Команда покажет путь к конфигурации. Открой папку, в которой лежит этот файл, затем `CustomApps`.
3. Скопируй прежнюю папку `stats` в безопасное место как резервную копию. Не очищай данные Spotify: история хранится в localStorage, а не в папке приложения.
4. Из архива скопируй папку `stats` в `CustomApps`, соглашаясь на замену файлов. Итоговый путь: `CustomApps\stats\index.js`, а не `CustomApps\stats\stats\index.js`. Важно перенести также новый файл `src\design.js` и обновлённый `manifest.json`.
5. Выполни `spicetify config custom_apps stats`, затем `spicetify apply`.
6. Перезапусти Spotify и открой Stats.

## Жанры

В исходной истории жанров нет. Здесь они задаются вручную: открой «Назначить жанры исполнителям», выбери исполнителя, введи один основной жанр и нажми «Сохранить». Это личная классификация, а не официальные данные Spotify. Незаполненные позиции остаются «Без жанра». Чтобы удалить метку, выбери исполнителя, очисти поле и сохрани.

Каждое прослушивание учитывается ровно один раз — по первому исполнителю трека. Доли вычисляются от всех подробных записей выбранного периода, включая неизвестный жанр. Старые месячные итоги не содержат достаточно подробностей и исключены из жанровой диаграммы. Поэтому жанровый блок за всё время может охватывать меньше записей, чем общие счётчики.

Никакие предустановленные жанры, проценты или демонстрационные прослушивания в приложение не добавлены. Метки хранятся отдельно в `spicetify-stats:manual-genres:v1`; исходные ключи истории не изменены. Очистка данных Spotify может удалить локальную историю и метки. Автоматической синхронизации нет.

## Что изменено

- Карточки с рамками, мягкими градиентами и цветами активной темы.
- Читаемые HTML-рейтинги вместо масштабируемого мелкого текста SVG.
- Кольцевая диаграмма жанров, полосы долей и редактор меток.
- График минут по дням с доступной текстовой таблицей.
- Компактный календарь без чрезмерного растягивания.
- Русские заголовки новых блоков. Исходные сообщения импорта и календаря оставлены на английском.
- Нет внешних библиотек, сетевых запросов и внешних картинок. Сборщик `extension.js` не изменён.

## Откат

Закрой Spotify, верни резервную папку `stats`, выполни `spicetify apply`, перезапусти Spotify. Не удаляй localStorage. Если новая версия показывает ошибку, пришли её текст и версии `spicetify -v` / Spotify.

Проверки выполнены в имитации окружения Spicetify. В настоящем клиенте Spotify эта сборка не проверена; совместимость с конкретной версией нужно подтвердить после установки.
